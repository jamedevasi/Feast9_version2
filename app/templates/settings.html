Automatic Logout

Signs a user out when their screen has been left alone, so patient details aren't left open on a shared computer. Typing or moving the mouse on any Feast9 page counts as activity. However busy, everyone signs in again after {{ absolute_session_hours }} hours.

Sign-in Security

Two-step sign-in asks for a code from an authenticator app on the user's phone as well as their password. Each user sets it up for themselves under My Account.

  • When required, an admin or doctor who hasn't set it up is taken to the setup page and can't open anything else until it's done. Receptionists can choose to use it unless the second box is ticked.
  • A forgotten password can only be reset from the login page by someone who has two-step sign-in: it asks for their security answer and a code. For anyone else, an admin sets a new password from Users.
  • Passwords must be at least {{ min_password_length }} characters and can't be a common password, repeated characters or contain the username. This applies when a password is set or changed.
  • After {{ account_max_failed }} wrong passwords or codes in a row an account is locked for {{ account_lock_minutes }} minutes. An admin can unlock it sooner from Users.
